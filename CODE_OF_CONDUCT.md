# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work and not the person, and make room for people who are new. Harassment, personal attacks and sustained disruption are not tolerated.

Report unacceptable behaviour privately to the maintainers through GitHub's "Report content" or by opening a private security advisory on this repository. Reports are handled confidentially.
